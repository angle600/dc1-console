# 02 · 手机配网（无需装 App）

## 0. 原理

ESPHome 的 `wifi.ap` + `captive_portal`：
设备**连不上预置 SSID 时自动开热点**并跑一个强制门户（DNS 劫持 + HTTP 重定向），
手机连上热点会自动弹出配置页；改完保存 → 设备重启 → 连新 WiFi。

```
上电 → 尝试 secrets.yaml 里的 ssid（20s）
        ├─ 成功 → 正常工作，热点关闭
        └─ 失败 → 开 AP: DC1-Setup / dc1setup (192.168.4.1) → 等待手机配置
```

## 1. 首次配网步骤（iPhone / Android 通用）

1. 插排上电，等 30 秒。手机 WiFi 列表出现 **`DC1-Setup`**。
2. 连接它，密码 `dc1setup`（见 `firmware/dc1-ai.yaml` 的 `wifi.ap.password`，建议自己改）。
3. 手机通常会自动弹出"登录网络"页；没弹就浏览器打开 `http://192.168.4.1`。
4. 页面里：
   - **SSID**：选家里的 **2.4GHz** 网络（ESP8266 **不支持 5G**）
   - **Password**：WiFi 密码（WPA2-PSK；WPA3-only 网络连不上，需在路由器开混合模式）
   - 可选 **Static IP**（见下）
5. 点 **Save / Connect** → 设备重启（约 10s）→ 手机 WiFi 会自动跳回家里网络。

## 2. 配网成功后验证

```bash
ping dc1-plug.local
# 或不支持 mDNS 的环境：
ping 192.168.36.xx          # 路由器 DHCP 列表里找 MAC 对应项

python ../tools/dc1ctl.py state
```

浏览器打开 `http://dc1-plug.local/` 可看到 Web 控制台（用户名/密码见 `secrets.yaml`）。

## 3. 建议：固定 IP（两条路，选一条）

**A. 路由器 DHCP 静态绑定（推荐，零固件副作用）**
OpenWrt：`网络 → DHCP/DNS → 静态地址分配`，绑定模组 MAC（`esphome logs` 或 Web 首页可见）。

**B. 固件写死**：取消 `firmware/dc1-ai.yaml` 里 `manual_ip` 注释，填
`static_ip / gateway / subnet / dns1`，OTA 一次生效。**注意**：写错网关会失联，
只能靠串口或按键重配，第一次建议先用 A。

## 4. 重新配网（换 WiFi / 密码改了 / 搬家）

| 方式 | 操作 |
|---|---|
| 改路由器前先改设备 | 保持旧 WiFi 可用时，用 Web 界面 `WiFi` 段或 `esphome run dc1-ai.yaml` 改 `secrets.yaml` 后 OTA |
| 已失联 | 断电 → 上电，设备连不上就自动开 `DC1-Setup`，按第 1 节重配（**原有 secrets 不会被删**，等于临时覆盖） |
| 强制开热点 | 连续断电上电 3 次（间隔 <5s）可触发 fallback；或串口 74880 观察日志 |
| 彻底重置 | 串口下发 `esphome` 命令行不可用时，`erase_flash` 重刷（会丢配置） |

## 5. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫描不到 `DC1-Setup` | 设备已连上旧 WiFi | 正常；先用旧网络 IP 访问，或改 `secrets.yaml` |
| 弹不出配置页 | 手机把热点判为"无互联网" | 手动开浏览器访问 `192.168.4.1`；Android 选"保持连接" |
| 保存后一直连不上 | 选了 5G / WPA3 / 隐藏 SSID | 换 2.4G + WPA2；隐藏 SSID 需 `fast_connect: true` |
| 连上就掉线重启 | 电源带不动 / 信号弱 | 看 `dc1ctl.py state` 的 WiFi 信号；别塞金属箱；检查 3.3V |
| `dc1-plug.local` 解析不了 | Windows 未装 mDNS / 跨网段 | 直接用 IP；或装 Bonjour |
| 密码含特殊字符 | YAML 引号 | `secrets.yaml` 里用双引号包住 |

## 6. 安全提示

- 默认 AP 密码 `dc1setup` 只是防误连，**配完网后设备不再开热点**；但建议改成 12 位随机。
- `secrets.yaml` 不进 git（已在 `.gitignore`）；`api_encryption_key` 泄露 = 局域网内可开关你的插座。
- 不要做端口映射把 6053/80 暴露到公网；要远程就套 VPN 或走 MQTT over TLS。
