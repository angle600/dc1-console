# 08 · TC1 换脑方案（ESP8266 + MicroPython）

> 配套：`hardware/tc1/`（电路资料）、`firmware/tc1/`（固件）、`cli/dc1ctl.py`（控制）、
> `gui/`（上位机，按 `type` 自动切面板）。

## 0 结论先行

| 问题 | 答案 |
|---|---|
| TC1 能直接刷 DC1 那套 MicroPython 吗？ | **不能**。原厂主控是 A1=MXCHIP EMW3031（MiCO）、A2=HF-LPT230（汉枫固件），都不是 ESP8266 |
| 那本仓库怎么支持 TC1？ | **换脑**：拆掉原模组，焊 ESP-12S 转接板 → 跑 `firmware/tc1/`，协议与 DC1 一致 |
| 不想动硬件呢？ | A1 刷 [zTC1](https://github.com/a2633063/zTC1)（MiCO Cube 编译 + J-LINK）；A2 刷 [TC1A2](https://github.com/limbang/TC1A2)（汉枫 SDK + UART 230400）。两条都不在本仓库工具链内 |
| TC1 能测电压电流吗？ | **不能**（出厂只贴了 BL0937 的 CF 功率通道，CF1/SEL 支路是空焊盘），只能测功率 |

## 1 DC1 vs TC1

| 项 | DC1 | TC1 |
|---|---|---|
| 形态 | 4 位排插 + 3 USB | 收纳盒排插，6 位 + 4 USB（1 路 QC3.0） |
| 主控 A1 / A2 | ESP8266（CSM64F02 ≙ ESP-WROOM-02） | A1 = EMW3031-P（Cortex-M4F）／A2 = HF-LPT230 |
| IO 扩展 | CAT9554（I²C） | 无，继电器直挂 MCU GPIO |
| 继电器 | 1 总 + 3 分 | 6 只，各自一路（无独立总继电器） |
| 计量 | CSE7766（UART，V/A/W） | BL0937（CF 脉冲，**只有 W**） |
| 总开关 | 总继电器 | 盒体**机械开关** + App 的"总控"（固件广播 6 路） |
| USB | 受总继电器控制 | 独立降压板，**不受 MCU 控制** |
| 刷机 | UART0 串口 / OTA | 换脑走 ESP 串口；原厂 A1 走 SWD、A2 走 UART |

## 2 拆机

1. 抠开靠近插座那侧的两个橡胶脚垫，露出 **T9 中孔梅花螺丝**（2 颗）。
   批头要买 **T9 中孔梅花（Torx Tamper-Resistant T9，标 TR9 / T9H / "带孔梅花"）**：
   螺丝头中心有凸台，**普通实心 T9 插不进去**；南旗 22 合一这类套装一般不含此批头。
   螺丝沉在脚垫凹坑里，优先选 **4 mm 六角柄细杆批头** 或 **L 型 T9 中孔扳手**（1/4" 批头外径 6.35 mm 容易被凹坑挡住）。
2. 拧掉螺丝后倒扣，在硬面上敲 2 下、软面敲 4 下，插座组件整体脱出。
3. 先拍照记录模组丝印，判 A1/A2（对照 `hardware/tc1/image/12-A1与A2主控对照.png`）。
4. **动烙铁前先拆下电源板与绝缘塑料片**，否则热风枪会把塑料吹化。

## 3 换脑接线表（ESP-12S / ESP-12F）

选脚原则：避开 ESP8266 三个启动 strap（GPIO0 低=下载模式、GPIO2 低=启动失败、
GPIO15 高=启动失败），所以 6 路继电器只占 5/4/14/12/13/16。

| ESP-12S 脚 | GPIO | 接到板上 | 说明 |
|---|---|---|---|
| D1 | 5 | RELAY1 | 插孔 1 |
| D2 | 4 | RELAY2 | 插孔 2 |
| D5 | 14 | RELAY3 | 插孔 3 |
| D6 | 12 | RELAY4 | 插孔 4 |
| D7 | 13 | RELAY5 | 插孔 5 |
| D0 | 16 | RELAY6 | 插孔 6（GPIO16 无中断，只作输出，正好） |
| RX | 3 | BL0937 CF（U3 光耦集电极） | 10 kΩ 上拉，下降沿中断计数；**运行时不作串口收** |
| ADC0 / TOUT | — | 按键（原 nReload 按键改接分压） | 10 kΩ + 10 kΩ 分压，按下 ≈1.65 V，判定阈值 <1.0 V |
| GPIO2 | 2 | 面板 LED（低电平点亮） | 外部 10 kΩ 上拉，保证 strap 为高 |
| TX | 1 | 不接（或留测试点） | 烧录/救砖用 |
| 3V3 / GND | — | 板上 LDO 3.3 V / GND | **必须共地**，模块峰值电流 350 mA，就近加 100 µF |

继电器驱动电平由转接板决定：NPN/ULN2003 是**高电平吸合**（`RELAY_ACTIVE_LOW = False`），
若是光耦低有效驱动，把 `firmware/tc1/board.py` 里 `RELAY_ACTIVE_LOW` 改成 `True`（只此一处）。

焊接：热风枪 400 ℃ 吹掉原模组 → 清焊盘 → 上锡膏 → 焊转接板 → 3M 胶固定 ESP-12S，
天线朝外壳外侧（金属盒里信号会明显变差）。

## 3.1 有没有引脚兼容的 ESP32 模组？

**结论分两层**：

1. **对原厂脚位（EMW3031 / HF-LPT230）：没有。** 这两块是厂家私有 LCC/SMT 封装，
   没有任何 ESP32 模组是 pin-to-pin 的，想换必须做转接小板（或飞线）。
2. **对"换脑"用的 ESP-12 脚位：有。** 安信可 **ESP-C3-12F** 明确 pin-to-pin 兼容
   ESP-12F/12E/12S/12L/07S/07，可以直接落在本方案的 ESP-12S 转接板上。

| 模组 | 尺寸 (mm) | 焊盘 | GPIO | 与 TC1 现有转接板 | 备注 |
|---|---|---|---|---|---|
| HF-LPT230（A2 原厂） | 22×13.5×3 | SMT18 | 16 脚 | — | 汉枫私有固件，UART 烧录 |
| EMW3031-P（A1 原厂） | 邮票孔 LCC | 25 + A1~A4/B1~B4 | 24 | — | MiCO，SWD 烧录 |
| **ESP-12S/12F（本方案）** | 24×16×3 | SMD-22 | 9 可用 | ✅ 基准 | ESP8266，1 MB |
| **ESP-C3-12F（ESP32-C3）** | 24×16×3.1 | SMD-22 | **15** | ✅ **同脚位可直插** | RISC-V 160 MHz / 400 KB / 4 MB |
| ESP32-C3-MINI-1 | 13.2×16.6×2.4 | 53 pad | 15 | ❌ 需转接板 | 体积最小，1.27 mm 间距 |
| ESP32-C3-WROOM-02 | 18×20×3.2 | SMD | 15 | ❌ 需转接板 | — |
| ESP32-WROOM-32E | 18×25.5×3.1 | SMD-38 | 30+ | ❌ 需转接板 | 脚数/尺寸都不同 |
| ESP-S3-12K（ESP32-S3） | 31×18×3.0 | SMD-42 | 38 | ❌ 需转接板 | 想上 S3 只能另画板 |

### 换 ESP-C3-12F 的话，要改什么

| 项 | 说明 |
|---|---|
| 脚位 | **脚"位置"兼容、脚"功能"不兼容**：D1/D2/D5… 是 ESP8266 的别名，C3 的 IO 编号完全不同。必须按 C3-12F 脚位图重排，不能照抄 |
| 启动 strap | C3 的 strap 是 **GPIO2 / GPIO8 / GPIO9**（GPIO9 拉低进下载，GPIO8 必须为高）。6 路继电器要避开这三个脚，否则上电会误吸合或进不了正常启动 |
| 固件 | 换 MicroPython 的 `esp32c3` 端口（4 MB Flash，双分区可做**整片 OTA**，比现在"只能传 .py"强得多） |
| 代码 | `machine` API 基本通用，两处要改：`board.py` 的 GPIO 号、`Key` 的 ADC 阈值（ESP32-C3 是 12 bit，0~4095，不是 0~1023） |
| 计量 | 不变，BL0937 CF 照样用 `Pin.irq` 计数；C3 的 GPIO 中断比 ESP8266 更宽裕 |
| 好处 | 9 路信号（6 继电器 + CF + ADC 按键 + LED）在 15 个 GPIO 里很宽裕；RAM 400 KB vs ESP8266 的 ~30 KB 堆，JSON/网页都不用抠内存了 |

一句话建议：**只是复活 TC1，ESP-12S 够用（本仓库已写好）；想要 4 MB + 整片 OTA + BLE，
就换 ESP-C3-12F，脚位不用改板，改 `board.py` 和烧 `esp32c3` 内核即可。**

### 3.2 ESPC3-12E-N4（DOIT 四博智联）能不能用？

**能用**，而且资源比 ESP8266 富余得多：ESP32-C3 / **4 MB Flash（N4）** / 400 KB SRAM /
15 GPIO / 24×16×3 mm / 3.0~3.6 V。手册已收在 `hardware/tc1/datasheet/ESPC3-12E_DOIT_datasheet.pdf`。

它是 **24×16 "通用脚位"**（DOIT 自称兼容 ESP-C3-12F、WB3S），机械上能焊到 ESP-12 系列的
焊盘上，但**只有 EN / VCC / GND 三个脚和 ESP-12F 同位置，信号脚全不一样**——按丝印 D1/D2
接线必翻车，必须照下面这张表。

#### 脚位（手册 Table 2.2 / Fig.2.1 实测核对）

| 脚 | 名称 | 脚 | 名称 | 脚 | 名称 |
|:--:|---|:--:|---|:--:|---|
| 1 | IO0（ADC1） | 9 | NC | 17 | IO10 |
| 2 | IO1（ADC1） | 10 | NC | 18 | **IO9（拉低=下载，strap）** |
| 3 | EN | 11 | NC | 19 | IO18（USB D-） |
| 4 | IO2（strap，内部上拉） | 12 | IO6 | 20 | IO19（USB D+） |
| 5 | IO3 | 13 | IO7 | 21 | RX0（IO20） |
| 6 | IO4 | 14 | NC | 22 | TX0（IO21） |
| 7 | IO5 | 15 | GND | | |
| 8 | VCC | 16 | IO8（strap，启动须高） | | |

#### TC1 在这块模组上的推荐分配

| 用途 | 引脚 | 说明 |
|---|---|---|
| RELAY1~6 | IO3 / IO4 / IO5 / IO6 / IO7 / IO10 | 全部避开 strap（IO2/8/9） |
| BL0937 CF | IO1 | 任意 GPIO 都能做下降沿中断 |
| 按键 | IO0 | ADC1 分压，阈值 **0~4095**（不是 1023） |
| LED | IO18 | 低电平点亮；不用 USB 时 IO18/19 都是普通 GPIO |
| 烧录 | TX0(22) / RX0(21) | 与 ESP8266 的接法一致：TX↔RX 交叉，IO9 拉低进下载 |
| 留空 | IO2 / IO8 / IO9 | strap，保持默认（IO2/IO8 高、IO9 高） |

9 个信号用掉 9 个脚，15 个 GPIO 还剩 6 个，扩展富余。

#### 三个坑

1. **天线**：官方型号表写得很清楚——**ESPC3-12E = U.FL/IPEX 外置天线**，
   ESPC3-12（不带 E）= 板载 PCB 天线。TC1 是金属化收纳盒，**选 12E 反而对**：
   用 IPEX 转接线把天线贴到外壳塑料面或盒外，比 PCB 天线埋在盒里强 10~20 dBm。
   （早前我按 Fig.2.1 的阴影误判成 PCB 天线，以型号表为准。）
2. **ADC 只有一组好用**：ADC1 = IO0~IO4，ADC2 只有 IO5 且 WiFi 工作时受限。按键放 IO0，
   别放 IO5。
3. **固件要换端口**：烧 `esp32c3` 版 MicroPython（4 MB），`board.py` 的 GPIO 号与 ADC 量程
   都要改；换来的是**整片 OTA + 双分区回滚**，比 1 MB 的 ESP8266 强一档。

> 选型建议：只求稳，用 **ESP-C3-12F**（安信可，资料/MicroPython 支持最全，官方明确
> pin-to-pin ESP-12F/12S）；ESPC3-12E 是 DOIT 的通用脚位版本，能用，但丝印与文档没安信可细。
> 两者焊盘同族，做转接板时按其中一块画即可。

### 3.3 能不能 PIN 对 PIN 直接替掉原模块？——不能

三块模组的焊盘实测对比（数据来自各自手册的机械图）：

| 项 | HF-LPT230（A2 原厂） | EMW3031-P（A1 原厂） | ESPC3-12E |
|---|---|---|---|
| 外形 | **22 × 13.5 × 3 mm** | **33 × 18 mm** | **24 × 16 × 3 mm** |
| 焊盘数 | 18（16 侧 + 2 底） | 33 半孔（25 编号 + A1~A4/B1~B4）+ 中央大焊盘 | 22（16 侧 + 6 底） |
| 焊盘间距 | **1.9 mm** | **≈1.2 mm** | **2.0 mm** |
| 焊盘尺寸 | 1.0 × 1.0 | 1.48 × 0.8 | 1.0 × 1.5 |
| 电源/地脚位置 | 15 = 3.3V，16 = GND | 16 = VCC_3V3，17 = GND | **8 = VCC，15 = GND** |
| 天线 | PCB / IPEX（-1 无 IPEX） | PCB，净空 15 mm | U.FL（12E）/ PCB（12） |

- 尺寸差 2~17 mm，间距差 0.1~0.8 mm，焊盘数 18/22/33 全不同 → **物理上插不上**。
- 电源脚位置也不同（LPT230 的 3.3V 在 15 脚，C3 在 8 脚），即便强行对位也会**烧模块**。
- 所以只有两条路：① 做 **转接小板**（原焊盘 → C3 焊盘，飞 6 路继电器 + CF + 按键 + LED）；
  ② 直接按 C3 重画一块小板，用排线接原板的继电器驱动端。
- 注意焊盘区尺寸：A1 的 33×18 空地能放下 24×16 的 C3，但 **U.FL 座 + 天线馈线** 要留出走线空间；
  A2 的 22×13.5 区域放 24×16 会**超出 2 mm**，得往外挪或选 ESP32-C3-MINI-1（13.2×16.6）。

## 4 烧录

```bash
# 1) 烧 MicroPython 内核（1MB 版；GPIO0 拉低进下载模式后复位）
python -m esptool --port COM5 erase_flash
python -m esptool --port COM5 --baud 460800 write_flash --flash_size=1MB \
       0x0 firmware/micropython-1m-v1.29.0.bin

# 2) 首次：串口传源码（含 config.json）
python tools/mp_deploy.py --serial COM5 --dir firmware/tc1

# 3) 之后：纯 WiFi 覆盖源码（设备已入网）
python cli/dc1ctl.py --ip 192.168.4.1 fw update --dir firmware/tc1
python cli/dc1ctl.py --ip 192.168.4.1 reboot
```

`fw update` 走 `PUT /api/file?name=...`（先写 `.new` 再改名，失败不留半截文件）；
不指定 `--dir` 时 CLI 会先读 `/api/info` 的 `type`，TC1 自动用 `firmware/tc1`。

## 6 API 差异（与 DC1 同一套协议）

只有两处不同，其余端点逐字一致：

| 端点 | DC1 | TC1 |
|---|---|---|
| `GET /api/state` | `total/1/2/3/logo` + `meter.voltage/current/power` | `total/1..6` + `meter.power/p_raw/k_imp/pulses/calibrated` |
| `POST /api/cal` | `{"voltage":..,"current":..,"power":..}` → 增益 | `{"power":<外部功率计读数>}` → 反算 `k_imp` |

```bash
python cli/dc1ctl.py discover                       # 列表里 TYPE 列显示 TC1
python cli/dc1ctl.py --ip 192.168.1.11 state
python cli/dc1ctl.py --ip 192.168.1.11 switch --ch 4 --on 1
python cli/dc1ctl.py --ip 192.168.1.11 cal --power 100   # 单点标定
```

## 7 功率标定

`P(W) = 1000 × f_CF(Hz) / K`，`K` 为脉冲常数（imp/kWh，出厂估算 1600）。

1. 接一个**稳定、已知功率**的阻性负载（100 W 白炽灯最省事），跑 1 分钟。
2. `python cli/dc1ctl.py --ip <ip> cal --power 100`
3. 回读 `meter`：`calibrated=1`，`k_imp` 落盘到 `config.json`，重启不丢。

注意：开关电源负载 PF≠1，CF 反映的是有功功率，与插排式功率计读数一般能对上；
若差得多，先怀疑线上有别的负载。

## 9 风险

- **强电**：6 路触点直接挂 220 V，调试时先贴绝缘胶带盖住铜条；刷机只用 3.3 V。
- **换脑不可逆**：原模组拆掉即失去原厂固件与保修；A1 的 SWD 焊盘留好，想回去还能刷 zTC1。
- **上电瞬态**：ESP-12S 复位期间继电器驱动脚是高阻，转接板务必带下拉，避免上电瞬间抖动吸合。
- **信号**：TC1 是金属化收纳盒，ESP-12S 板载天线要尽量贴外壳非金属面。
- **计量精度**：只有 CF 脉冲，轻载（<5 W）脉冲稀疏，1 s 窗口抖动大，读数会跳。
